# TrianguloY watchface (+ generator)

This repository contains my own watchface, as well as the custom Kotlin dsl I made to build it. The current state of the repo is minimal, only contains the actual features that I personally use. But I may update it from time to time whenever I need.

It was made for personal use, but made public for others to learn and/or use. Prs are welcomed but please be careful with their size.

I use a Creative commons License because the only thing I ask is that, if this was helpful to you, just mention me and provide a link to this repo (and if you want to contact me to show it I'll be glad to hear about it!)

- [generator](./generator/README.md) contains the kotlin dsl tool to buld custom watchfaces. This is just a tool, does nothing by itself, but when used will generate a custom [watchface.xml](./watchface/src/main/res/raw/watchface.xml) with your own design.

- [watchface](./watchface/README.md) contains the actual watchface android wear repo. There are some minor configurations for the actual watchface itself, but the important file is [watchface.xml](./watchface/src/main/res/raw/watchface.xml) that is generated by the [generator](./generator/README.md) tool.

- [definition](./definition) contains the definition of my own watchface, using the [generator](./generator/README.md) tool itself.

Not sure if good or bad, but everything here was made without using any AI at all (nor even the Android Studio AI predictions).
